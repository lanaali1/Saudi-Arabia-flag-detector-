Saudi Arabia Flag Detector 🇸🇦

AI-Powered Flag Detection Using YOLOv5

Overview

This project explores the application of Artificial Intelligence, Deep Learning, and Computer Vision to detect the Saudi Arabian flag in images using a custom-trained YOLOv5 object detection model.

The project demonstrates practical experience with object detection, model training, and visualizing detection results using Python.

Technologies Used

* Python – Programming language
* PyTorch – Deep learning framework
* YOLOv5 – Object detection architecture
* OpenCV – Image processing and visualization
* NumPy – Numerical operations
* Jupyter Notebook – Development environment

Project Workflow

1. Prepare image data for object detection.
2. Train a custom YOLOv5 model.
3. Evaluate the model using training and validation results.
4. Load the trained model using PyTorch.
5. Perform flag detection on an input image.
6. Visualize the detection results using OpenCV.

Model Evaluation

The project training outputs include:

* Confusion Matrix
* Precision Curve
* Recall Curve
* F1 Score Curve
* Training and Validation Visualizations

These outputs can be used to evaluate the model’s detection performance.

Running the Project

The notebook uses a custom YOLOv5 model through PyTorch Hub.

To run it on another computer, install the required dependencies, download the YOLOv5 implementation if needed, and update the local paths to the model weights and input images.

Note: The original notebook contains device-specific file paths. These must be updated for a different environment.
